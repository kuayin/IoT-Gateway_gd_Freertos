# 基于 GD32 与 FreeRTOS 的高可靠物联网边缘网关

## 项目简介
本项目基于 GD32F103C8T6 (Cortex-M3) 与 FreeRTOS 实时操作系统，从零构建了一个高可靠的物联网边缘节点。系统集成了高频数据通信、多传感器环境采集、本地 OLED 可视化交互、外挂 SPI Flash 存储以及IAP OTA 固件升级功能。

## 核心功能特性
- **零拷贝通信架构**：采用 DMA + 串口空闲中断 (IDLE) 接收不定长数据，结合环形缓冲区与读写双指针，实现任务层零拷贝解析。
- **抗干扰协议解析**：设计私有二进制通信协议（帧头+命令字+校验和），利用有限状态机解决网络通信中的粘包/半包问题。
- **多任务并发调度**：基于 FreeRTOS 划分多级任务（通信、采集、显示、看门狗），利用二值信号量实现中断到任务的同步。
- **总线资源保护**：引入互斥锁 (Mutex) 保护 I2C 和SPI总线，利用优先级继承机制防止优先级翻转，确保 OLED 与传感器的并发安全。
- **软硬 I2C和SPI 兼容**：底层驱动抽象，支持宏定义一键切换，规避死锁风险。
- **IAP OTA**：Bootloader，实现基于串口与 W25Q64 暂存的 OTA 固件升级。

##  硬件与软件环境
- **主控芯片**：GD32F103C8T6 (64KB Flash, 20KB RAM)
- **操作系统**：FreeRTOS
- **开发环境**：Keil MDK5, Trae (AI 辅助编程)
- **外设模块**：0.96寸 I2C OLED、I2C AHT20 、I2C BMP280、W25Q64 SPI Flash。

## 软件架构设计
- **中断层**：极简 ISR，只负责搬运坐标与发送信号量，不进行复杂业务处理。
- **驱动层**：封装 I2C (软/硬)、SPI(软/硬)、传感器、外部flash、OLED。
- **OS 层**：任务调度、互斥锁、信号量。
- **应用层**：通信、采集、显示、看门狗。

## 工程目录结构
```text
APP代码
├── CMSIS/            # 内核启动文件与系统配置
├── Firmware/         # GD32 官方标准外设库
├── FreeRTOS/         # RTOS 核心源码与移植层
├── User/             # 用户业务代码 (核心)
└── Project/          # Keil MDK 工程文件
└── README          

Bootloader代码
├── CMSIS/            # 内核启动文件与系统配置
├── Firmware/         # GD32 官方标准外设库
├── User/             # 用户升级代码 (核心)
└── Project/          # Keil MDK 工程文件
```

## 工程编译说明
本仓库包含两个 Keil 工程，请按以下顺序烧录：
1. `GD32_project1_app/`：主应用程序工程（起始地址 0x08004000）。
2. `GD32_IAP_Bootloader/`：引导程序工程（起始地址 0x08000000）。
